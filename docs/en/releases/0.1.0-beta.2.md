# C4thedral 0.1.0-beta.2

[English](0.1.0-beta.2.md) | [Deutsch](../../de/releases/0.1.0-beta.2.md)

Status: Public source beta

Date: 2026-09-03

This beta improves precise Route authoring and native document opening. It is
source-compatible with the executable `draft-1` model and View slices from the
previous beta except for the deliberately replaced experimental relationship-
label offset spelling described below.

## Changed

- Route labels now use the explicit independent properties
  `label-offset-x = <signed>du` and `label-offset-y = <signed>du`; the earlier
  tuple-shaped `label-shift` preview spelling is rejected.
- The graphical Route editor can preview, apply, and undo both label offsets
  while preserving automatic, guided, or fixed Route authorship.
- Route-policy completion now considers the controls already present. It no
  longer proposes `automatic` beside authored path controls or `fixed` without
  its required point list, while still offering `automatic` for Port values.

## Native document opening

- Packaged macOS applications declare `.c4ml` as an editable C4ML document type.
- Initial and already-running application instances accept operating-system
  **Open With** delivery through a bounded main-process queue.
- Windows and Linux packages accept the corresponding native path or local file
  URL arguments; the Debian package advertises the `text/x-c4ml` MIME type.
- The renderer receives only an opaque document handle and bounded source, and
  external opening keeps the existing unsaved-change protection.

## Validation

- The complete repository build, documentation, public-source, worker,
  architecture, type, and test gates pass.
- Language tests cover compatible policy-value completion, independent signed
  label offsets, omission, and reset behavior.
- Renderer output was inspected before and after horizontal and vertical label
  movement without changing the underlying Route.
- A local macOS arm64 package accepted one `.c4ml` document from a stopped state
  and a second document while already running. This is local development
  evidence, not a notarized public binary release.

## Distribution boundary

`v0.1.0-beta.2` remains a public source beta. Apple Developer ID signing and
notarization and Windows publisher signing remain required before C4thedral
presents native installers as official public downloads. The native evidence
recorded for `0.1.0-beta.1` on Windows and Ubuntu remains historical evidence;
it is not relabelled as a `beta.2` package run.
