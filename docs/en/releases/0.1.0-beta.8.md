# C4thedral 0.1.0-beta.8

[English](0.1.0-beta.8.md) | [Deutsch](../../de/releases/0.1.0-beta.8.md)

Status: Public source beta

Date: 2026-09-23

This beta introduces native project creation and explains how project sources,
shared architecture, Views, and exported images fit together.

## Project creation

- **Files → New project…** accepts a project name and opens a native parent
  directory picker. It creates a new directory with `c4ml.project.json`, three
  empty sources in `model/`, `relations/`, and `views/`, and a `docs/` directory.
- The project opens immediately with clean source tabs. Existing files and
  directories are never overwritten. Cancellation, invalid names, write
  failures, and protection of unsaved work have dedicated checks.
- The starter is language-owned; filesystem operations remain in the desktop
  adapter and the renderer receives opaque document handles.

## Project and output guide

- The German and English Markdown documentation and searchable in-app handbook
  now contain **From project to finished output**.
- The walkthrough explains shared model definitions, several Views, source
  inventory, saving, and single/all-View SVG/PNG export with executable commands.
- It explicitly distinguishes supported image exports from project resources
  that do not yet produce a complete PDF, HTML, or Word handbook.
- A scoped LF rule preserves the example's hash-verified passive asset on
  Windows checkouts.

## Validation and limits

The affected automated tests, type checks, documentation checks, production
renderer build, Windows packaging, and native artifact verification passed.
Native project creation and collision protection were exercised visually;
existing project files remained byte-identical after a collision. The packaged
German handbook and search were inspected, and the documented CLI exports ran
successfully with identical selected/all output for the single-View example.

This is not a fully green release gate: the final general packaged smoke in
this work reported `fontsReady: false`; its later detached-preview and PNG
steps were not reached. Existing Unix-path assumptions in the external-open
test remain a Windows test limitation. Exact evidence is recorded in the
[engineering test log](../../engineering/testing.md).

This remains a public source beta. No native installers are offered as
approved downloads for this state. Local Windows development artifacts are
unsigned; this change does not create a GitHub release. Signing and notarization
remain separate release work.
