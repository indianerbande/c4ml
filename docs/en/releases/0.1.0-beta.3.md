# C4thedral 0.1.0-beta.3

[English](0.1.0-beta.3.md) | [Deutsch](../../de/releases/0.1.0-beta.3.md)

Status: Public source beta

Date: 2026-09-03

This maintenance beta hardens the locked build dependency graph while retaining
Electron 44, Node.js 24, TypeScript 6, and the existing product behavior.

## Security maintenance

- The Electron rebuild and cache graph now resolves `tar` 7.5.22 instead of
  vulnerable `tar` 6.2.1.
- Forge's optional interactive-editor graph now resolves `tmp` 0.2.7 instead
  of vulnerable `tmp` 0.0.33.
- Angular CLI's development graph now resolves `qs` 6.16.0 instead of
  vulnerable `qs` 6.15.3.
- GitHub source checks now run a production dependency audit after installing
  the committed lockfile.
- Offline production checks require the reviewed overrides and reject the
  superseded vulnerable versions.

The production audit reports no known vulnerabilities. The complete
development audit still reports three high-severity findings in the build-only
`extract-zip` and `image-size` packages. Their upstream projects currently
publish no patched versions. They are absent from the application ASAR, remain
visible to Dependabot, and are recorded with their containment and replacement
boundary in the engineering dependency ledger.

## Validation

- The frozen-lockfile installation and production audit pass under Node.js
  24.15.0.
- The complete build, documentation, public-source, architecture, worker,
  type, and test gate passes with 570 tests.
- The macOS arm64 application, DMG, and ZIP were rebuilt under Node.js 24.15.0.
  Packaged smoke, ad-hoc deep signature verification, DMG verification, and ZIP
  integrity all pass.
- The packaged application contains none of `tar`, `tmp`, `qs`, `extract-zip`,
  or `image-size`.

## Distribution boundary

`v0.1.0-beta.3` remains a public source beta. Apple Developer ID signing and
notarization and Windows publisher signing remain required before native
installers are presented as official public downloads. Earlier Windows and
Ubuntu package evidence remains historical and is not relabelled as a
`beta.3` run.
