# C4thedral 0.1.0-beta.7

[English](0.1.0-beta.7.md) | [Deutsch](../../de/releases/0.1.0-beta.7.md)

Status: Public source beta

Date: 2026-09-08

This source beta turns the previously explanatory service guidance into a
complete, source-backed authoring path. C4ML still has no generic Service kind:
authors deliberately model a service at the C4 level that matches its actual
scope.

## Concrete service creation

- The element dialog now offers two direct choices: create a service as a
  Software System or as a Container inside a Software System.
- Container creation stays inside the same dialog. The author selects the
  owning Software System and either an existing Container View or a new one.
- Creating a Container together with a new scoped Container View and its
  initial visible membership is one reviewed, atomic, undoable source change.
- Adding a Container to an existing Container View reuses the same candidate
  preview and shared Undo/Redo history as other graphical authoring actions.
- The choices and form guidance are available in German and English without
  introducing hidden model or diagram state.

## Evidence and distribution boundary

- The repository gate passes with production builds, type checks,
  documentation checks, architecture checks, and the complete automated test
  suite.
- The German flow was also exercised through the locally served Angular
  application, including both service choices and the new Container-diagram
  fields.

`v0.1.0-beta.7` remains a public source beta. No native installers are offered as
approved downloads for this state. Apple Developer ID signing and notarization
and Windows publisher signing remain separate release requirements.
