# C4thedral 0.1.0-beta.6

[English](0.1.0-beta.6.md) | [Deutsch](../../de/releases/0.1.0-beta.6.md)

Status: Public source beta

Date: 2026-09-07

This source beta makes graphical authoring more explicit, contextual, and
predictable. Every graphical change remains a reviewable C4ML source edit; the
workbench does not introduce hidden architecture or layout state.

## Model, diagram, and layout authoring

- Every source-change dialog identifies its scope as Architecture model,
  Active diagram, or Diagram layout and explains the consequence.
- Adding an element to the shared model, showing or hiding it in one diagram,
  and deleting it from the model are separate operations with separate review
  and history entries.
- The Diagrams area now activates and manages declared Views. Authors can edit
  a diagram's title and purpose, change its visible content, or delete only
  that diagram without deleting the shared architecture model.
- A model-only starter creates just the header, model label, and empty model.
  The workbench then guides new authors from elements to their first diagram.
- Frequent object-specific actions are available from the diagram context menu
  while toolbar and keyboard access continue to use the same commands.

## Clear C4 distinctions

- Static Relationships are reusable architecture facts. Dynamic interaction
  steps are ordered, View-local occurrences that explicitly select an existing
  directed Relationship.
- Logical Software Systems and Containers remain separate from their running
  Deployment instances. Several instances may reference the same logical
  element without copying or changing it.
- Service terminology explains when a logical service should be represented as
  a Software System, Container, or Component according to its scope.

## Editing behavior

- Graphical source changes share one chronological Undo/Redo history across
  element, connection, diagram, placement, and route operations, including
  document-addressed dirty-state restoration.
- Modal editors close only through their explicit actions. Selecting or
  dragging text no longer dismisses a dialog.
- The Handbook button toggles both the tab and its highlighted activity state.
- Independent signed horizontal and vertical relationship-label offsets are
  supported by the language, completion provider, renderer, and route editor.
- Invalid route-policy suggestions were removed from completion.
- Compiler-worker failure handling now rejects obsolete responses, retries once
  without losing project source, and offers an explicit localized retry path.

## Evidence and distribution boundary

- The complete repository gate passes with 648 tests, the Angular production
  build, TypeScript checks, documentation checks, production-boundary checks,
  worker checks, and the deterministic architecture proof.
- The new German and English authoring flows were exercised through a locally
  served Angular application, including preview, apply, Undo, and Redo.

`v0.1.0-beta.6` remains a public source beta. No native installers are offered as
approved downloads for this state because their current host-specific packages
have not been rebuilt and revalidated. Apple Developer ID signing and
notarization and Windows publisher signing remain open release requirements.
