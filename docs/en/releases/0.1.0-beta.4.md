# C4thedral 0.1.0-beta.4

[English](0.1.0-beta.4.md) | [Deutsch](../../de/releases/0.1.0-beta.4.md)

Status: Public source beta

Date: 2026-09-03

This source beta fixes the graphical Route editor preview lifecycle and records
the next interaction-design priority.

## Route preview correction

- Opening the Route editor now captures the selected Route, active View,
  document, and project revision as one bounded authoring session.
- Starting a candidate preview no longer lets a changing main-diagram selection
  dismiss the dialog before the worker response arrives.
- The result pane shows an explicit progress state while the candidate SVG is
  compiled.
- Valid, invalid, and failed preview responses remain reviewable until the
  author cancels or successfully applies the source change.

## Interaction follow-up

Frequent object-specific actions should become available through right-click
context menus derived from the clicked object and current compiler context.
Toolbar, keyboard, and command-palette access remain equivalent paths, but a
distant generic button should not be the only way to invoke a contextual
action.

## Validation

- The exact reported `200du`/`0du` label-offset change was proposed and parsed
  successfully against the original local architecture document without
  modifying it.
- All 571 repository tests, including 250 editor tests, and the TypeScript gate
  pass.
- The Angular production build and documentation, production-editor, and worker
  bundle checks pass.

## Distribution boundary

`v0.1.0-beta.4` is a public source beta. Native installers have not been rebuilt
or revalidated for this change; an installed `beta.3` application does not
contain the correction. Apple Developer ID signing and notarization and Windows
publisher signing remain open release requirements.
